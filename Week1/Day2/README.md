# Week 1 - Day 2 SQL Practice

## Overview

This folder contains Day 2 SQL practice exercises completed as part of the Databricks Training program. The practice focuses on advanced SQL concepts including sorting, joins, nested queries, correlated subqueries, aggregate analysis, and combined moderate-level SQL problems.

The queries were executed using relational tables including Employee, Department, and Project.

---

## Topics Covered

### ORDER BY Queries
The following concepts were practiced:
- Sorting records in ascending order
- Sorting records in descending order
- Multi-column sorting
- Ordering grouped data

### JOIN Queries
Different types of joins and relational operations were implemented:
- INNER JOIN
- LEFT JOIN
- Department and Employee mapping
- Project and Department relationships
- Handling NULL relationships
- Employee-project association queries

### Nested and Correlated Queries
The following advanced SQL concepts were covered:
- Subqueries
- Correlated subqueries
- Aggregate comparison queries
- Department-wise salary analysis
- Second highest salary queries

### Combined Moderate Difficulty Queries
Complex analytical queries were implemented using:
- Aggregate functions
- GROUP BY and HAVING clauses
- Nested conditions
- Department-wise analysis
- Multi-condition filtering
- Salary and age comparisons
